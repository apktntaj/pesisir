# KLASIFIKASI BARANG (HS CODE)

## 1. Pengertian

**Harmonized System (HS)** adalah sistem internasional untuk:

* Penamaan (deskripsi) barang
* Pemberian kode numerik (HS Code)

Digunakan untuk mengklasifikasikan barang dalam perdagangan internasional.

Sistem ini dikembangkan oleh **World Customs Organization (WCO)** (sebelumnya *Customs Co-operation Council*).

---

## 2. Penggunaan

* Digunakan oleh lebih dari **200 negara**
* Mencakup sekitar **95% perdagangan dunia**
* Dipakai oleh:

  * Otoritas pabean
  * Serikat ekonomi
  * Pelaku perdagangan internasional

---

## 3. Struktur HS Code

HS Code standar terdiri dari **6 digit**:

* **2 digit pertama** → Bab (Chapter)
* **4 digit pertama** → Pos / Heading
* **6 digit lengkap** → Subpos / Sub-heading

Contoh struktur:

```
XXXXXX
||||
||||__ Sub-heading (6 digit)
||____ Heading / Pos (4 digit)
______ Chapter / Bab (2 digit)
```

---

## 4. Pengembangan oleh Negara

* Negara anggota diperbolehkan menambahkan digit tambahan
* Tujuan:

  * Kebutuhan nasional
  * Kebijakan tarif dan non-tarif

Contoh:

* **ASEAN menggunakan 8 digit HS Code**

---

## 5. Struktur Nomenklatur HS

Pengelompokan barang disusun secara logis berdasarkan tingkat proses produksi:

1. **Raw material** (bahan mentah)
2. **Unworked product** (barang belum diolah)
3. **Semi-finished product** (barang setengah jadi)
4. **Finished product** (barang jadi)

---

## 6. Struktur Sistem HS

* **21 Bagian (Sections)**
* **97 Bab (Chapters)**
* **±1.222 Pos (Headings)**
* **±5.800 Subpos (Sub-headings)**

---

## 7. Sumber Referensi Klasifikasi

Untuk menentukan HS Code secara tepat, digunakan beberapa referensi tambahan:

* **Alphabetical Index**
  → Daftar barang secara alfabet

* **Explanatory Notes (EN)**
  → Penjelasan resmi tiap pos/subpos

* **Compendium of Classification Opinions**
  → Kumpulan keputusan klasifikasi oleh WCO

* **Database HS**
  → Basis data digital klasifikasi

* **Amendments**
  → Perubahan atau pembaruan HS

* **Nomenclature**
  → Struktur resmi daftar HS

---

## 8. Catatan Penting

* HS Code bersifat **standar global sampai 6 digit**
* Digit setelahnya bersifat **nasional/regional**
* Ketelitian klasifikasi sangat penting karena berpengaruh pada:

  * Bea masuk
  * Pajak
  * Regulasi impor/ekspor

# PPJK Study Notes

## Hari 2 — Fondasi Berpikir Klasifikasi Barang

> **Target:** Memahami *bagaimana* seorang PPJK berpikir saat mengklasifikasikan barang, bukan menghafal nomor HS.

---

# 1. Pergeseran Cara Berpikir

Kemarin kita belajar:

> **Apa yang diklasifikasikan?**

Hari ini kita belajar:

> **Bagaimana proses klasifikasi dilakukan?**

HS Classification bukan aktivitas mencari nomor, tetapi **proses pengambilan keputusan berdasarkan aturan**.

---

# 2. KUM-HS adalah "aturan bermain"

BTKI hanyalah daftar nomenklatur.

Yang menentukan **bagaimana** membaca daftar tersebut adalah **KUM-HS (General Rules for Interpretation/GIR).**

Insight hari ini:

> **HS bukan kamus. KUM-HS adalah metode untuk menggunakan kamus tersebut.**

---

# 3. Klasifikasi adalah hasil, bukan titik awal

Urutan berpikir yang benar:

```text
Barang
↓
Identifikasi karakteristik objektif
↓
Terapkan KUM-HS
↓
Tentukan Pos/Sub-pos
↓
HS Code
↓
Tarif, LarTas, PDRI, dll.
```

Bukan:

```text
Invoice
↓
Salin HS Code
```

---

# 4. Source of Truth

Yang menjadi dasar klasifikasi adalah:

> **Karakteristik objektif barang.**

Dokumen hanyalah alat bantu.

Contohnya:

* Invoice
* Packing List
* Brosur
* Katalog
* Datasheet
* Website pabrikan
* HS Code dari eksportir

Semuanya adalah **evidence**, bukan **authority**.

---

# 5. HS Code bukan identitas barang

HS Code adalah **hasil dari proses klasifikasi**.

Yang diklasifikasikan adalah barangnya.

Nomor HS hanya menjadi cara untuk menyatakan hasil klasifikasi tersebut.

---

# 6. Struktur HS lebih mudah dipahami sebagai pohon

Daripada menghafal:

```
84
8471
8471.30
```

lebih mudah membayangkan:

```text
Section
└── Chapter
    └── Heading
        └── Subheading
            └── National Subheading
```

Setiap level mempersempit ruang kemungkinan.

---

# 7. Tetapi HS bukan tree biasa

Pada setiap level terdapat aturan yang dapat mengubah arah klasifikasi:

* KUM-HS
* Section Notes
* Chapter Notes
* Explanatory Notes

Artinya kita tidak hanya "turun ke bawah", tetapi juga harus memeriksa aturan yang berlaku.

---

# 8. Hipotesis menarik hari ini

Anda mengamati bahwa urutan Bab tampaknya bergerak dari:

> **produk alam → bahan baku → hasil manufaktur → mesin → barang jadi**

Kita belum menyimpulkan bahwa ini adalah filosofi resmi WCO, tetapi pola tersebut memang terlihat dan dapat membantu memahami struktur besar BTKI.

---

# Insight Hari Ini

Kalimat yang menurut saya paling penting untuk diingat besok pagi adalah:

> **"Seorang PPJK tidak mencari HS Code. Seorang PPJK berusaha memahami barang, lalu menggunakan aturan untuk menemukan klasifikasi yang benar."**

Kalau satu kalimat ini benar-benar tertanam, materi KUM-HS 1 sampai 6 nanti akan terasa jauh lebih mudah.
